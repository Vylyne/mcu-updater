# Mainsail fork retired

This document is retained only as a historical marker. The former
`Vylyne/mainsail` fork and its release channel are no longer maintained, and
this project no longer installs or ships a forked Mainsail client.

Use the standalone UI in `ui/`. It communicates with the Moonraker agent and
may be embedded in Mainsail with an iframe. Existing Moonraker Update Manager
integration and Mainsail config/editor links remain supported.

Do not follow the historical branch, release, or update-manager instructions
that were formerly documented here; they are unsupported.
